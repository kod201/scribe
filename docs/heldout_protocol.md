# Held-out set — capture protocol (PRD 12.1)

This directory is **gitignored and stays that way**. Nothing in it may appear
in a public repo, a prompt, or fine-tuning data. It is the only data that
sign-off metrics (PRD 12.2) may be computed on.

## Why homemade

Public datasets may overlap the model's training data, so accuracy on them
proves nothing. Pages created here, after the model's training cutoff and never
published, are the only trustworthy measure.

## Protocol

1. **Print** `templates.pdf` (generated by `scripts/make_heldout_templates.py`),
   or better, the actual study CRFs / Zambia MoH / WHO register layouts if you
   have them — match the real target forms as closely as possible.
2. **Hand-fill with fabricated data only.** No real patient data, ever.
   - ≥ 3 different writers, deliberately spanning neat → rushed handwriting.
   - Include the hard cases on purpose: ages written "Ad", struck-through and
     overwritten values, blank fields, unticked checkbox rows, values that
     overflow their boxes, day-first dates in several formats.
3. **Photograph with a phone** — slight angle, imperfect lighting, the way a
   busy clinic actually captures paper. No flatbed scans.
4. **Name the images** `HO_001.jpg`, `HO_002.jpg`, ... and put them in
   `images/` here.
5. **Transcribe to gold** (see below). Transcribe exactly what is written; the
   gold value for something illegible or absent is `null`.

Targets: **≥ 10 pages to start tuning, ≥ 50 before v1 sign-off**, spread
across all four page types.

## Building gold.csv

Two passes, both offline:

```bash
# pass 1: emits types.csv with one row per image -- fill in each page's type
uv run python scripts/heldout_gold_skeleton.py

# pass 2 (after filling types.csv): emits gold.csv with one row per
# applicable field, gold_json empty -- fill each with a JSON value
uv run python scripts/heldout_gold_skeleton.py --from-types
```

`gold_json` is JSON: strings quoted (`"Ngozi Abara"`), numbers bare (`34`),
absent/illegible is `null`, tables are arrays of row objects (copy the column
keys the skeleton provides). Same encoding as `samples/flow/gold.csv` — crib
from there.

## Running the evaluation

```bash
uv run scribe ingest samples/heldout/images --schema amr_flow_v1
uv run scribe run
uv run scribe eval --gold samples/heldout/gold.csv --set heldout
```

`--set heldout` labels the report; only those reports count for sign-off.
Targets (PRD 12.2): auto-accepted accuracy ≥ 98%, flag rate ≤ 30%,
hallucination ≤ 2% on fields marked legible.

## Contamination check (PRD 12.3) — once per model revision

1. Print 3 pages from the **flow** set and hand-alter a few handwritten values
   (change a date, an age, a drug name). Note exactly what you changed.
2. Photograph, name them `CC_001.jpg` ..., put them in `images/`.
3. Ingest + run, then compare the extractions for the altered fields against
   what you wrote: if the model returns the **original** values instead of your
   edits, it is recalling training data, not reading — record that in
   `docs/bench.md` and treat all flow-set accuracy for that model as
   meaningless.
